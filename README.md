# Adaptive smelting


### a simple yet useful mod
#### what does it do?
**it adapts the smelting bulk based on your current smelting material**\
for example:\
you put coal in and it bulk smelts 2 items at once

## all supported materials
* lava: 4
* kelp (block): 3
* coal: 2
* wood (all types): 1
* everything else: 1
